# Code of Conduct

XGZ Jazz aims to be a constructive, technically focused open-source learning project.

Participants are expected to:

- discuss ideas and corrections respectfully;
- critique content rather than people;
- explain theory disagreements with reproducible musical reasoning or sources;
- avoid harassment, discrimination, threats, and personal attacks;
- respect copyright, attribution, and contributor licensing.

Project maintainers may edit, reject, hide, or remove contributions or participation
that materially disrupts the project or violates these expectations.

For moderation matters, use the private contact method published by XGZ Labs rather
than opening a public issue containing sensitive personal information.
